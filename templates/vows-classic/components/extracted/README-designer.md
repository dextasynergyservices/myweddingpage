Sample template scaffold for "Vows Classic (Sample)".

Instructions:

1. Replace files in `assets/` with your high-quality images.
2. Edit `manifest.json` to update `planIds` with real plan UUIDs from your system.
3. Edit or replace components in `components/` and zip them to `components.zip` if you want custom React components.
4. Zip the package root files into `sample-template.zip` and upload in Admin → Templates → Upload.

Notes:
- The provided components are minimal placeholders. Real template components should follow project conventions and use CSS modules in `styles/`.
- Do not reference server-only APIs from client components.
